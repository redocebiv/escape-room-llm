Prompt Injection Escape Room

Get the password out of the assistant. Every room adds a real defence.

Talk your way out.

Each room has a chat assistant guarding a password. Get it to tell you, type the password into the unlock box, and the next room opens — with a new defence you’ll have to get around.

  • Every room teaches one prompt-injection technique from OWASP LLM01:2025.
  • The last room flips it: you build the defence, and a red-team battery of attacks tries to break it.
  • The assistant is not a language model. It’s a deterministic rule engine written in JavaScript, built to fall for the same tricks real models fall for. Escape a room and you can see every rule it used.

The “get the password” format comes from Lakera’s Gandalf. Go play that too.
